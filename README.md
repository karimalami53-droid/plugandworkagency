# Plug and Work Agency

A simple static website for a real‑estate agency, generated from the local development server (`http://localhost:8080`).

## Features
- Responsive layout
- Property listings (static HTML placeholders)
- Contact form (Netlify Forms compatible)

## Deployment
The site is configured for **Netlify** via `netlify.toml`. After pushing the repository to GitHub, connect it to Netlify (free tier) to obtain a live URL such as `https://plugandworkagency.netlify.app`.

You can later add a custom domain (e.g., `plugandworkagency.com`) in the Netlify dashboard.
